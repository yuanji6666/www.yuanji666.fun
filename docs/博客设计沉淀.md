# 博客设计沉淀

这份文档记录当前博客已经确认的设计理念与实现边界，作为后续迭代的约束。

## 核心原则

- 内容优先，设计退后
- 个人展示优先，博客内容其次
- 纯净、克制、安静、耐看
- 像书本、文档、研究笔记，而不是产品首页
- 所有视觉元素都必须有明确存在理由

## 页面目标

- 默认进入页面时先看到个人介绍
- 顶部导航负责切换主题
- 页面只显示当前主题内容，不同时堆叠多个区块
- 阅读体验优先于展示效果

## 布局规则

- 单栏为主
- 内容整体居中
- 两侧留白要大，让页面像纸面排版
- 不使用右侧栏
- 不使用首页 Hero Banner
- 不使用复杂卡片布局
- 不使用重复的主题标题

## 导航顺序

当前顶部导航顺序固定为：

1. About
2. Blog
3. Projects
4. Notes

其中 `About` 是默认优先入口。

## 视觉语言

- 背景必须是纯白色
- 不要米白、暖黄、渐变、发光、毛玻璃
- 不要浅灰色横向分隔线
- 不要彩色装饰元素
- 仅保留必要的文字层级和极少量边界感

## 字体与排版

- 保留当前字体方向
- 正文字号克制
- 行高舒适
- 通过字号、粗细和留白建立层级
- 尽量让文字自然呼吸，不依赖装饰性边框

## 组件边界

页面只保留最必要的信息结构：

- 顶部导航
- 主题内容面板
- Markdown 文章内容

避免为了组件而组件，避免引入无实际阅读价值的区块。

## 交互方式

- 顶部主题点击切换内容
- 默认显示个人介绍
- 切换时保持页面干净，不增加额外动画负担
- 不需要右侧目录栏
- 不需要底部标语

## Markdown 内容

文章内容应保持阅读友好，支持：

- 标题
- 引用
- 表格
- 数学公式
- Mermaid
- 代码高亮
- 脚注

这些能力只为提升内容表达，不应反过来制造视觉噪音。

## 需要避免的东西

- 右侧 Latest notes 栏
- 多栏布局
- 浅灰色主题标签重复出现
- 横向分隔线过多
- 卡片化首页
- 过强的装饰感
- 额外口号文案

## 当前状态

页面应当呈现一种感觉：

这里没有多余的东西。

它像一本长期整理的技术笔记，安静、稳定、清楚。

如果以后要继续修改，优先遵守这条：

**让内容自己说话，设计尽量消失。**
