# 极简技术博客设计提示词

请设计一个用于展示 Markdown 技术笔记的个人博客。

使用Vue框架

整个网站应遵循**内容优先（Content First）**的理念，让读者关注文字本身，而不是界面。

## 设计理念

追求极简、克制、安静、高级、耐看。

不是"设计很多"，而是"设计得刚刚好"。

整个网站应该像一本排版精美的技术书籍、一份经过认真整理的研究笔记，而不是一个互联网产品首页。

希望它能够在十年后依然不过时。

设计应体现以下关键词：

* 极简（Minimalism）
* 内容优先（Content First）
* 永恒（Timeless）
* 克制（Restraint）
* 安静（Quiet）
* 专注（Focused）
* 工匠精神（Craftsmanship）

任何一个元素，都应该有存在的理由。

如果一个元素不能提升阅读体验，就不要出现。

---

## 参考风格

整体气质参考：

* https://matklad.github.io/
* Unix 文档
* Linux Manual（man page）
* 学术论文
* 高质量纸质书籍
* 日本杂志的留白与排版

不是科技公司官网。

不是 SaaS 产品。

不是炫酷作品集。

更像一个程序员安静记录知识的地方。

---

## 页面布局

采用单栏布局。

正文宽度控制在 680～760px。

大量合理留白。

内容居中。

左对齐排版。

使用稳定而有节奏的垂直间距。

页面结构尽可能简单：

顶部：

* Blog
* Notes
* Projects
* About

下面直接就是内容。

不要 Hero Banner。

不要巨大的标题。

不要宣传文案。

不要复杂卡片。

不要各种装饰。

首页应该让人立即开始阅读，而不是浏览设计。

---

## 字体设计

字体是整个网站最重要的设计元素。

优先保证阅读体验。

建议：

正文：

* 霞鹜文楷（LXGW WenKai）或思源宋体

英文：

* Inter

代码：

* JetBrains Mono 或 Maple Mono

要求：

* 舒适的行高
* 合理的字间距
* 克制的字号
* 清晰的层级

尽量利用字体粗细和字号建立层次，而不是依赖颜色和边框。

---

## 配色

整体采用低饱和度配色。

只需要浅色模式：

* 温暖的白色背景
* 深灰色正文
* 浅灰色辅助文字

整个页面尽量只有一种强调色：

链接颜色。

除此之外，不需要彩色装饰。

避免：

* 渐变
* 发光
* 毛玻璃
* 彩色阴影
* 高饱和按钮

---

## Markdown 渲染

网站主要用于阅读 Markdown。

需要支持：

* 标题
* 引用
* 表格
* 数学公式（KaTeX）
* Mermaid
* 代码高亮
* 脚注

所有元素都应该保持统一、克制。

代码块应像 VS Code 的编辑器，而不是炫酷终端。

---

## 动画

动画应尽量少。

允许：

* 页面淡入
* 按钮轻微 Hover
* 平滑滚动

不要：

* 大面积动画
* 飞入效果
* 视差滚动
* 加载动画
* 漂浮组件

整个网站应该感觉"瞬间打开"。

---

## 组件

整个网站尽量只有：

* Header
* Article
* Table of Contents
* Footer

不要为了组件而组件。

如果 Markdown 能表达，就不要额外设计。

---

## 性能

性能也是设计的一部分。

目标：

* JavaScript 尽可能少
* CSS 尽可能精简
* 页面体积尽可能小
* 加载速度极快
* 部署后输出纯静态页面

希望网站像打开本地 Markdown 一样迅速。

---

## 希望传递的气质

整个网站应该给人这样的感觉：

"这里没有任何多余的东西。"

它安静、自信、克制。

它不像一个产品，更像一本长期积累的知识笔记。

它不会刻意展示作者，而是让内容自然地说话。

阅读时，人会忘记网站本身，只专注于文字与思想。

请始终记住一句话：

**设计应该消失，内容应该留下。**
