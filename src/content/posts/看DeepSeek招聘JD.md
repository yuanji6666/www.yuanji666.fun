# **Agent Harness 研发/工程方向**

加入 DeepSeek Harness 团队，探索和解决面向下一代 Agent Harness 的工程难题。

**【主要职责】**

1. 参与设计 DeepSeek 的 Harness 产品的技术架构与选型。
2. 参与开发 DeepSeek 的 Harness 产品。
3. 与研究员紧密合作，共同定义和实现 Harness 领域的前沿创新。
4. 与模型训练团队的工程师与研究员深度沟通与合作，参与实现**模型与 Harness 的共同进化，从 Harness 的角度实现 DeepSeek 的 Harness 与模型的深度适配。**
5. 以**内部真实任务做为 Harness 产品和模型相关能力训练的重要反馈源**，持续迭代产品能力。
6. 理解并分析团队收集到的用户反馈。在有兴趣且力所能及的前提下，协助维护 Harness 产品用户社群。
7. 协助项目管理相关工作。

**【任职要求】**

1. 技术水平过硬，技术眼界广阔。
2. 知名高校本科学历及以上。
3. 熟练使用 AI Agent 工具进行软件开发。在软件开发领域具有极强的学习能力。能够**在 AI 辅助下**，在**没有直接经验**的领域（如语言、技术、框架等）进行有**质量保证**的编程工作。
4. 是 **Agent 产品的高强度用户**，对 Agent Harness 的开发有极大的**热情**，对模型行为有**品味**有**判断力**，对开发者体验有强感知。深度使用过代码类及通用类Agent产品，并将相关产品的使用融入到自己的工作和生活中。
5. 熟悉 LLM 以及 Agent 基本机制及其技术原理，包括 LLM API、KV Cache、Agent Loop、Tool Use、Reasoning、Planning、Skills、MCP、Memory、Subagent、Multi-Agent 等相关知识。对 Prompt Engineering、Context Engineering、Harness Engineering 等课题有较深入的了解。
6. 良好的中文沟通能力。

**【加分项】**

1. AI行业相关软件开发经验。
2. 作为**小团队中的研发工程师快速迭代产品的经验**。
3. 个人**开源**作品及开源社区的深度贡献。
4. 与研究员深度协作的经验或科研经验，有科研品味。
5. 能用英文与**开源社区**、用户社群沟通。
6. 计算机科学领域、编程领域、或数据科学领域具有含金量的比赛奖项。
7. 计算机科学及其它学术领域具有含金量的论文发表。
8. 其它超乎常人的与此工作相关的才能。

## ideas

最近DS官网开放了招聘入口，方向覆盖算法研究员，infra，全栈开发，Harness，仔细读了一遍JD后，觉得完全可以作为AI时代下计算机学生的方向指导和学习目标了。

着重看了Harness研发的JD，发现了不少有意思的。

首先，为什么要做自己的Harness?

主要职责的第四条讲了产品定位，Harness需要和模型共同进化。如果没有自己的harness产品，就不得不被动适配Claude Code的接口，受制于人，根本没法释放模型的能力。

第五条也很有意思: 以内部真实任务作为能力反馈，往往是一线工程师能最直观感受到工具是否趁手好用，只有自己愿意用，才有底气给别人用。

任职要求方面，有几个关键词值得注意: AI辅助/质量保证/Agent高强度用户/热情/品味/判断力

其实AI时代对工程师底层能力的要求没有变，打好计算机基础还是必要的。本质上，Harness还是一个系统设计问题，计算机基础培养的是人的计算思维，比如抽象，封装，tradeoff。代码可以AI辅助生成，但是最后为代码质量兜底负责的还是人。

生产效率和工作流程确实发生了革新，同时还要求你必须以身入局: 兴趣，热情，品味，判断力，做出好的工具为自己所用，这些才是最好的迭代驱动力。也许在这个时代我们的学习可以更纯粹一点！

加分项里面，着重强调了开源影响力，着实，当今时代最好的想法创新往往在开源社区萌芽，抛开一些概念炒作不谈，开源贡献比绩点更能体现一个人的技术品味和对复杂项目的把握能力。

还特别有一条令人意外——小团队里的快速迭代经验: 在AI解放生产力的当下，越来越能感受到开发者的全栈能力是越来越被强调的，我们也许可以不再是庞大体系中的一颗螺丝钉，有时候精简高效的小团队反而更能降低沟通成本，迸发出巨大能量。

所以在这个时代，我们也许不用过早局限自己，广泛了解各种技术，尝试各种岗位，做自己感兴趣的——了解所有事，更能做好一件事，而AI让这些成为可能。
